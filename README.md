# BBaert Photography Portfolio

A static photography portfolio website with distinct categories for portraits, events, landscapes, and commercial work.

## Files

- `index.html` — portfolio homepage with category sections and gallery filter
- `styles.css` — responsive portfolio styling
- `script.js` — category filter interaction

## How to use

1. Open `index.html` in your browser.
2. Update the hero text, category descriptions, and contact details.
3. Add your portfolio images to the local category folders:
   - `architecture/`
   - `street/`
   - `nature/`
   - `studio/`
4. Update `gallery-manifest.json` with the filenames you add.

## Notes

This site is built without a build step. For a local preview, use VS Code Live Server or run:

```bash
python -m http.server
```
